# 工业智能体复杂方法图：设计契约

版本：2026-10-17。用途：为实际论文设计提供可编辑样板；不是已经验证的方法或实验结果。

## 图1：系统总览

核心信息：Agent 先判别经验适用性，再通过工具与约束检查提出行动，并以经过核实的结果更新经验。
原型：三栏全景＋底部闭环。左栏为工业观测，中间大面板强调条件记忆，右栏为工具执行。
层级：中心候选筛选表和门控为主；波形、过程小图与执行 DAG 支撑主线；图例和来源说明较安静。
空间：1420×960；A x20..320，B x355..1035，C x1070..1400；主体 y100..700；底部反馈 y760..890。跨栏连线只用栏间专用通道。
可删性：不增加与判别、执行、反馈无关的 Transformer/LLM 装饰层；不填虚构性能数字。

## 图2：机制展开

核心信息：语义相关性与经验适用性分开判断；适用性未知不能被当作通过。
原型：三面板对照。候选经验 → 三值条件矩阵与掩码 → 证据确认与版本更新。
层级：矩阵为中心 hero；左边候选记录说明高相关但过期的反例；右边更新分支明确成功、失败与未验证的区别。
空间：1420×850；左 x20..405，中 x440..960，右 x995..1400；主体 y100..710；底部 y750..810。
边界：示例布尔值、波形及记录为教学 fixture；未知如何处理是候选设计，不宣称新颖性或有效性。
