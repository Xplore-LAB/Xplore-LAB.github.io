色卡

目前收录 39 篇文章、373 组配色、1878 个色值（其中 66 色经人工逐色核对）。色值来自公众号「观科研」科研配色系列文章的色卡原图，经人工核对与本地 OCR 提取后归档。 本页把图形按承担的科研表达任务分成 A–G 七类共 79 种（而非只按外观分），每种都标注用途、推荐绘图方法、规范提示与优先级；所有示意图均为模拟数据，用于检验一组配色画在真实图表里的上色效果。 最上面的「配色工作台」是快捷入口：左栏挑 79 类图表之一、右栏挑任意一组色卡，中间大画布立即试画，可切四图联看、随机搭配、收藏搭配、下载 SVG；它和下面的图谱、色卡库、右侧预览共用同一份状态，任意一处改动全页同步。 色卡按文章、色数、风格或来源分类聚合，默认收起；展开后点一组配色，右侧与上方图鉴会同步换色，可切换色盲模拟、派生 OKLCH 色阶、查看 CIEDE2000 配色体检，并最多并排对比 4 组。另内置经典科研色板，也可上传图片自动提色直接试画。点色块复制 HEX，卡片按钮导出 matplotlib / ggplot2 / CSS 代码。

用色值请以 HEX 为准。RGB 由 HEX 反算，原图标注与 HEX 不一致的已在对应组里标出； 含红绿搭配的组，投稿前把「色觉模拟」切到红色盲 / 绿色盲检查是否还能区分，并配合形状、纹理或线型区分。模拟色只作用于预览，复制与导出的始终是原文色值。

选用与说明

怎么挑一组

  • 先用顶部工作台搭配：左栏按 A–F 六类挑图表、右栏按组名 / HEX / 期号搜色卡，中间大图实时试色；「四图联看」一次看同组色在 4 类图上的表现，「随机搭配」快速找灵感，「☆ 收藏搭配」把满意的「图表 + 色卡」组合存在浏览器本地，下次一键恢复。工作台的色觉 / 色阶 / 透明度与下方右侧预览完全联动。
  • 2–3 组对照：选 2–4 色的渐层或成对浅色组，主次靠明度拉开，最稳。
  • 8–10 类多分类：用高饱和多色相组（箱线图、气泡图、UMAP、细胞比例堆叠图）。
  • 综述插图 / 机制示意：用全低饱和的奶油色组，观感柔和，不抢正文。
  • 按科研表达任务选图：上方图谱把 79 类图形分成 A 基础对比 / B 分布统计 / C 时序动态 / D 机器学习 / E 关系结构 / F 空间优化 / G 论文组合，点缩略图即选中；右侧按类切换、用「下一个」依次轮看，看这组色画在该类图表里是否清晰。
  • 逐图元数据与代码模板：每个图都标了编号、英文名、主要用途、推荐绘图方法和投稿规范提示；「复制该图 Python 模板」会带上当前配色生成可运行骨架，「导出图谱 JSON」可拿走全部 79 条元数据。
  • 统一规范：先用页面里的 paper.mplstyle 固定字号、线宽与导出格式，再注入色卡；单栏 89 mm、双栏 183 mm（Nature），默认 600 DPI，投稿前按期刊要求调整。
  • 色阶扩展：色数少的组可派生浅色 / 明暗变体（×2 或 ×3）；线性模式是简单混合，OKLCH 模式在感知均匀空间里调亮度，中间段不发灰。图表默认用满组内全部颜色。
  • 色觉模拟：切到红色盲 / 绿色盲 / 蓝黄色盲 / 灰度自查，避免红绿直接对比；还可拖透明度滑块模拟半透明填充叠放。
  • 配色体检：展开右侧「配色体检」，看最小 CIEDE2000 色差、色盲模拟后的色差、灰度亮度差、白底对比度、命名冲突与建议类别数。
  • 无障碍方案：内置 Okabe-Ito、Paul Tol 等色盲友好色板，在「经典色板」下拉里可直接选来试画；更多资源见 科研绘图 · 素材与资源。
