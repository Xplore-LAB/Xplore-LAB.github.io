动手试一下

点击「一键填充」，观察字段被逐个识别并填入；带 review 标记的字段会进入待确认清单。真实插件在此基础上多了字段别名库与跨站控件打分。

自检报告：6 个字段高置信填充，2 个字段建议人工确认（期望年薪置信度 0.62，项目经历为长文本建议校对）。真实插件还会对每站生成填写诊断，标出未识别控件。

这背后是什么

  1. 字段别名库：姓名 / name / fullname / 姓名(中文) 等写法映射到同一语义字段，覆盖主流网申系统。
  2. 控件识别打分：对 input / select / textarea 及 React、Vue 受控组件按标签文本、占位符、DOM 上下文综合打分，低置信字段标记 review。
  3. 填写自检：填充完成后逐字段回放校验，输出可直接核对的诊断报告。
