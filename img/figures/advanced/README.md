# Editable research figure examples

These are original educational diagrams, not reproductions of paper figure artwork. All matrix cells, curves and performance numbers are schematic or synthetic, never experimental findings. References are listed in manifest.json.

Edit SVG text, groups and connectors in Inkscape. Regenerate with Python 3, numpy, matplotlib and Inkscape on PATH: `python scripts/build_advanced_figures.py`. PDFs are vector exports; PNGs are previews. The Transformer follows classic post-norm ordering; DPO refers to the original offline preference objective.

Synthetic dataset: seed 42, 3 methods × 3 conditions × 20 independent simulated draws. Error bars: mean ± 1.96 × sample SD / sqrt(20), an approximate normal interval. Response traces and cost-quality points are separately constructed examples. Panel (d) summarizes exactly the same observations as (b), and is not independent evidence. Replace fixtures with actual, protocol-linked results before research use.
